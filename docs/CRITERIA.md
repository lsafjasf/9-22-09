# 收敛判据适用性说明

三种判据都实现同一协议 `is_converged(state) -> bool`，可在
`IterativeSolver(criterion=...)` 处互换，调用点不变。
选择依据是“你想让‘收敛’表达什么语义”，而不是哪种算得更快。

## 1. 绝对残差 `AbsoluteResidualCriterion(tol)`

判据：`‖r‖ ≤ tol`

- **适用**：右端项 `b` 的量级已知且稳定，残差的绝对大小有直接物理
  意义（如残差就是误差、不平衡力的绝对上限）。
- **不适用/风险**：`b` 的量级变化时，同一个 `tol` 可能过松（解远没
  收敛就停）或过严（永远达不到、走满 `max_iterations`）。换一批
  数据就要重新调 `tol`。

## 2. 相对残差 `RelativeResidualCriterion(tol)`

判据：`‖r‖ ≤ tol · ‖b‖`

- **适用**：大多数场景的默认选择。对 `b` 的缩放不变（`b → αb` 时
  停止点不变），无需随数据重新调参；`tol` 直接对应“残差相对右端
  项压低了多少个数量级”。
- **不适用/风险**：`‖b‖` 很小（近零右端）时阈值被压得过严，可能
  不必要的多迭代；此时应改用绝对判据。另外它衡量的是相对 `b`
  而非相对初始残差 `r₀`，若 `x₀` 已经很好（`‖r₀‖ ≪ ‖b‖`），
  它仍要求压到 `tol·‖b‖`，可能偏严。

## 3. 残差下降率 `ResidualDecreaseRateCriterion(rate, min_iterations)`

判据：平均几何下降率 `(‖r_k‖/‖r_0‖)^(1/k) ≤ rate`，且 `k ≥ min_iterations`

- **适用**：关心“迭代是否足够快地在压残差”而非“残差是否足够小”。
  典型用途：
  - 多层/嵌套求解中做**早期分类**：快速确认当前预条件/参数组合
    收敛速度达标，不达标就尽早换策略，而不是烧完 `max_iterations`；
  - 只需要把残差压低若干数量级、不关心绝对精度的粗求解阶段
    （如多重网格的预平滑、内层迭代的宽松停止）。
- **不适用/风险**：
  - 它**不保证最终精度**：满足下降率时残差可能仍较大（对比脚本中
    identity 组合在残差 1.8e-02 处即停）。需要精度保证时应使用
    绝对/相对判据。
  - 对“先快后慢”的迭代（如 Richardson 在谱分布不均时，早期快、
    尾部贴近渐近收敛因子），平均下降率会被早期的高速拉低，可能
    过早判收敛；`min_iterations` 可缓解但无法根除。
  - `rate` 必须大于迭代的渐近收敛因子，否则永远触发不了、走满
    `max_iterations`（例如本仓库测试矩阵上 identity+Richardson
    的渐近因子 ≈ 0.99，`rate=0.3` 就不会触发）。

## 对照速查

| 判据 | 停止语义 | 对 b 缩放 | 保证最终精度 | 典型 tol/rate 量级 |
|---|---|---|---|---|
| 绝对 | 残差绝对量足够小 | 敏感 | 是（绝对意义） | 物理量误差上限 |
| 相对 | 相对 `‖b‖` 足够小 | 不变 | 是（相对意义） | 1e-6 ~ 1e-12 |
| 下降率 | 平均每步压得足够快 | 不变 | 否 | 0.5 ~ 0.9 |

验证：`compare_combinations.py` 在同一方程组上跑 3 预条件 × 3 判据
共 9 种组合，并对每种组合做与其判据语义一致的最终残差断言；
`tests/test_combinations.py` 将同样的断言固化进单元测试。
